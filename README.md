# GitAnalytics OSS 📊

GitAnalytics OSS is a local-first, zero-dependency git log visualization utility. It generates a single, self-contained HTML dashboard from your local git history without sending any code or parameters online.

## Installation & Usage

No installation or node modules required. Run it instantly inside any local Git repository:

```bash
npx git-analytics-oss
```

This will write a file `git-analytics-report.html` to your current working directory. Double-click it to load the interactive dashboard.
